# Guia introdutório dos usuários

Este guia apresenta as áreas funcionais do sistema em termos gerais. Os nomes exatos de botões e telas podem variar conforme a versão da aplicação.

## Perfis existentes

| Perfil | Finalidade geral |
|---|---|
| Administrador | Acompanhar e administrar a configuração geral do sistema |
| Secretaria | Gerenciar cadastros, organização acadêmica e solicitações administrativas |
| Professor | Consultar turmas e registrar informações acadêmicas |
| Aluno | Acompanhar informações escolares e atividades disponíveis |
| Responsável | Acompanhar os alunos vinculados, mensagens e Saída Segura |

## Acesso

O acesso é realizado na página de login. Cada usuário é direcionado às áreas permitidas para seu perfil. Não compartilhe contas ou senhas e encerre a sessão em dispositivos compartilhados.

## Fluxo de retirada pelo responsável

1. Entre no sistema com uma conta de responsável autorizado.
2. Acesse a área de Saída Segura e escolha um aluno com autorização de retirada.
3. Inicie a solicitação e, quando solicitado, permita o uso da localização no navegador.
4. Acompanhe o estado da solicitação: `Aguardando`, `No raio`, `Preparando` e `Liberado`.
5. Aguarde a confirmação da equipe escolar. O GPS por si só não finaliza a retirada.

## Fluxo da Secretaria

1. Acesse o painel autorizado de Saída Segura.
2. Acompanhe as solicitações e o status exibido.
3. Após a confirmação de entrada no raio, altere a solicitação para `Preparando`.
4. Após realizar os procedimentos internos de conferência, confirme `Liberado`.

## Observações

- O ambiente acessível atualmente é uma **demonstração acadêmica**, não um serviço de retirada de alunos para uma escola real.
- A geolocalização depende de permissão e disponibilidade no dispositivo.
- Nunca compartilhe publicamente logins, senhas ou dados de alunos na documentação.
